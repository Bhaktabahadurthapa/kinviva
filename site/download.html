Download

Get MeetingLens.

Version 0.1.4. Free for Mac and, as an experiment, Windows. No account.

Download MeetingLens.dmg

Version 0.1.4 · 9.5 MB

  1. Open the downloaded .dmg and drag MeetingLens onto Applications.
  2. Open it. macOS says it can't verify the app because this early version isn't notarized by Apple yet. Click Done.
  3. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to MeetingLens.
  4. Allow Microphone and Screen & System Audio Recording when asked, then quit and reopen once.
  5. Add an AI key (for example Gemini) in Settings → AI provider, or set up Ollama and whisper.cpp for a fully local setup.
Download for Windows

Version 0.1.4 · 6.1 MB · Built and unit-tested on a Windows server, not yet tried on a real laptop. Read my screen is Mac-only for now.

  1. Run the installer. Windows shows "Windows protected your PC" because it isn't signed yet: click More info → Run anyway. It installs for your user only.
  2. Open MeetingLens and allow Microphone access when Windows asks.
  3. System audio is captured from your default output device, so play the call through your normal speakers or headphones.
  4. Add an AI key in Settings → AI provider, or set up Ollama for Windows and whisper.cpp and set the paths in Settings → Speech recognition.

Before you install

What you need.

An AI model

A key for a cloud model such as Gemini, or a local model through Ollama. A vision-capable model is needed for Read my screen.

Speech recognition

The built-in whisper.cpp engine on Mac, or Deepgram if you prefer the cloud.

Permissions

Microphone and, on Mac, Screen & System Audio Recording. MeetingLens never changes your system permissions for you.

Verify your download

Every release lists SHA-256 checksums. On a Mac, run this in Terminal and compare the result with the release notes:

shasum -a 256 ~/Downloads/MeetingLens.dmg
