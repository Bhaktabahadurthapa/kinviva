Kinviva for Mac

macOS 13 or later, Apple silicon

Download MeetingLens.dmg

Version 0.1.4 · about 9.5 MB

  1. Open the downloaded .dmg and drag Kinviva onto Applications.
  2. Open it. macOS says it can't verify the app because this early version isn't notarized by Apple yet. Click Done.
  3. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to Kinviva.
  4. Allow Microphone and Screen & System Audio Recording when asked, then quit and reopen once.
  5. Add an answer engine key (for example Gemini) in Settings → AI provider (renamed Answer engine in 0.1.5), or set up Ollama and whisper.cpp for a fully local setup.

Kinviva for Windows experimental

Windows 10 or 11, 64-bit

Download for Windows

Version 0.1.4 · about 6 MB · built and unit-tested on a Windows server, not yet tried on a real laptop. Read my screen is Mac-only for now.

  1. Run the installer. Windows shows “Windows protected your PC” because it isn't signed yet: click More info → Run anyway. It installs for your user only.
  2. Open Kinviva and allow Microphone access when Windows asks.
  3. System audio is captured from your default output device, so play the call through your normal speakers or headphones.
  4. Add a key in Settings → AI provider, or set up Ollama for Windows and whisper.cpp and set the paths in Settings → Speech recognition.

Want the new workspace now?

Build it from source.

Everything on the Features pages is in the source code. If you are comfortable with developer tools, you can build version 0.1.5 yourself today.

  1. Install Node.js and Rust (rustup).
  2. git clone https://github.com/Bhaktabahadurthapa/kinviva.git and open the folder.
  3. npm install
  4. npm run tauri build builds the app for your computer. The README has the details, including the macOS permissions note.

Before you install

What you need.

An answer engine

A key for a cloud model such as Gemini, or a local model through Ollama. A model that can read images is needed for Read my screen.

Speech recognition

The built-in whisper.cpp engine on Mac, or Deepgram if you prefer the cloud.

Permissions

Microphone and, on Mac, Screen & System Audio Recording. Kinviva never changes your system permissions for you.

Verify your download

Every release lists SHA-256 checksums. On a Mac, run this in Terminal and compare the result with the release notes:

shasum -a 256 ~/Downloads/MeetingLens.dmg
